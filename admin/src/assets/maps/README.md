# Machine World Map

Shared UI source: `src/components/machines/MachineWorldMap.vue`.
Grouping and marker placement: `src/utils/machineWorldMap.js`.

`world.json` is generated by `node scripts/build-machine-world-map.mjs` from
Natural Earth's public-domain 110m data:
https://github.com/nvkelso/natural-earth-vector/tree/master/geojson
The dataset is bundled locally; visitors do not contact a map provider.

The admin uses a lazy-loaded Vue component. Public and user monitors use the
same component compiled by `node scripts/build-monitor-map.mjs` into
`../wyx_v2board/public/assets/monitor-map/`. Rebuild and deploy that directory
when changing the shared component, and bump the asset version in
`public/assets/monitor-map-loader.js`. That loader receives only the rows
already authorized for its host page; it does not fetch admin APIs.

Positions represent regions, not machine coordinates. Small-region anchors
are provided for HK, MO and SG, which are absent from the low-resolution data.
